02

About

Philosophy

보이지 않는 안정성을 책임진다

완성된 화면보다 그 뒤에서 데이터가 어떤 경로로 저장·반환되는지에 흥미를 느낍니다. 백엔드는 기능을 만드는 자리가 아니라 동시성·인증·데이터 정합성 같은 안정성을 책임지는 자리라고 생각합니다.

Problem Solving

"성공 응답 ≠ 정상 동작"

화면이 정상적으로 넘어가는 것을 정상 동작으로 믿지 않습니다. 오류가 났을 때 요청·실행된 쿼리·저장 결과를 각 단계에서 직접 확인하고, 어디까지 정상인지 먼저 확정한 뒤 범위를 좁혀 나갑니다.

How I Learn

배운 것을 다음 날 코드로

약 8개월간 주간에는 전공 수업, 저녁에는 백엔드 양성 과정을 병행하며 배운 내용을 다음 날 바로 코드로 옮기는 방식으로 공부해 왔습니다. 순수 PHP → Laravel → Spring Boot로 스택을 넓혀 왔습니다.

Why Backend

요청 하나가 만드는 부하와 예외

세 가지 스택을 거치며 확인한 것은, 기능이 동작하는 것에서 멈추지 않고 요청이 몰릴 때·권한이 어긋날 때·예외가 발생할 때를 함께 고민해야 한다는 점이었습니다.
