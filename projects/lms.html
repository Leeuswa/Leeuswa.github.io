LMS 학습 관리 시스템

JavaSpring BootSpring Data JPASpring SecurityH2REST APIGradle

개요

학생·교사·관리자가 각기 다른 권한으로 움직이는 온라인 학습 관리 시스템(LMS)입니다. 프론트엔드와 분리된 REST API 백엔드로, 저는 관리자·교사 파트를 맡았습니다.

인덕대 타닥타닥 동아리에서 Spring Boot와 React로 진행한 팀 프로젝트입니다. Controller-Service-Repository 계층을 분리하고, Spring Security로 역할을 구분했으며, 강의–수강–과제–채점을 엔티티 연관관계로 모델링해 프론트엔드와 독립적으로 개발·연동할 수 있는 구조로 설계했습니다.

담당 파트 (관리자 · 교사)

01회원 · 인증

  • 회원가입·로그인 구현, Spring Security로 학생·교사·관리자 역할별 접근제어
  • 역할에 따라 접근 가능한 기능을 분리해 권한 경계를 명확히 처리

02강의 · 수강

  • 강의 등록·관리 기능과 학생 수강 신청 흐름 구현
  • 학습 진행도 관리로 수강생별 진행 상태 추적

03과제 · 채점

  • 과제 등록 → 학생 제출 → 교사 채점으로 이어지는 흐름을 엔티티 연관관계로 모델링
  • 강의–수강–과제–채점이 연결된 데이터 흐름을 REST API로 일관되게 제공

04게시판

  • 게시판·댓글 기능 구현
  • 목록 조회·작성 등 기본 CRUD를 API로 제공
