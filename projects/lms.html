Overview

개요 · 왜 만들었는지

학생·교사·관리자가 각기 다른 권한으로 움직이는 온라인 학습 관리 시스템(LMS)입니다. 인덕대 타닥타닥 동아리에서 Spring Boot + React로 진행한 팀 프로젝트로, 프론트엔드와 분리된 REST API 백엔드가 필요했습니다.

전체 엔티티 12개 · API 66개 규모이며, 저는 관리자·교사 파트를 맡아 강의·수강·과제·채점·게시판을 REST API로 설계했습니다.

Problem Solving

문제 해결

프론트엔드 분리 연동 (CORS)
ProblemReact 프론트엔드와 분리된 구조에서 API 호출이 CORS 정책으로 차단됐습니다.
Cause서버가 다른 오리진에서 오는 요청을 허용하지 않았습니다.
Solution허용 오리진·메서드·헤더를 명시한 CORS 설정을 구성했습니다.
Result프론트엔드와 안정적으로 연동되는 REST API 환경을 구축했습니다.
Why

기술 선택 이유

WHYREST API 분리 구조

React 프론트엔드와 독립적으로 개발·연동하기 위해 계층과 응답 구조를 명확히 나눈 REST API로 설계했습니다.

WHYSpring Security

학생·교사·관리자가 접근할 수 있는 기능이 달라, 역할 기반 접근제어로 권한 경계를 명확히 했습니다.

WHYH2 Database

초기 개발·테스트 단계에서 빠르게 스키마를 검증하기 위해 인메모리 H2를 사용했습니다.
